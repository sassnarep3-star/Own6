# NBA Lines Lab

A research dashboard and auditable framework for originating NBA betting lines. It does **not** publish picks, current sportsbook prices, or a claimed profitable edge: this repository begins with no licensed historical odds/result dataset. Unknown empirical values are deliberately left blank and surfaced for review.

## Repository audit

The starting repository contained only `README.md` (six bytes, `# Own6`); no data, source code, tests, deploy configuration, or prior research were present. The pages distinguish sourced NBA facts from proposed modeling choices. NBA official statistics and injury reporting are linked at the point of use; all tables contain a source or explicitly state that a source cannot establish the requested value.

## Publish

GitHub Pages is configured to deploy the repository root using the included GitHub Actions workflow. Enable Pages in repository settings with **GitHub Actions** as the build/deployment source if it is not already enabled. This is a static, dependency-free site.
