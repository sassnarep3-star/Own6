Two coefficients, recomputed from the raw finals

Correlation is where a parlay stops being a lottery ticket and starts being a single bet with a disguised price: two legs that move together cannot be multiplied. The two coefficients below are recomputed here from the 121 committed final scores with an implementation written separately from the pipeline that produced them.

Reading the numbers honestly

A coefficient of 0.018 between game margin and game total means spread and total legs are close to uncorrelated at game level — but the interval published alongside it ([-0.161, 0.1959]) spans zero, so the honest statement is "no dependence detected at this sample size", not "independent". Independence is an assumption to be tested, never a default. Team-total legs are a different matter: home and away scoring correlate at about 0.1994 because both teams play the same pace.

Where a third decimal could mislead

A second correlation table in the repository (data/correlation_findings.csv) quotes r = 0.2004 on n = 92 for the same home-versus-away pair, while this table quotes r = 0.1994 on n = 121. Both are arithmetically reproducible; they are computed on different date cut-offs. Publishing the same pair twice with different samples and no label is how a reader ends up citing the number that suits them. Logged as X-02.
