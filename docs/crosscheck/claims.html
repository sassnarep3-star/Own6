The one drift that matters. The landing page promises 10 validation gates per candidate and the lab page prints G01–G10, but data/methodology.json defines eight (G1–G8) — the Korean-law gate, provenance, integrity screen, out-of-sample test, sample size, closing-line benchmark, multiplicity correction and correlation gate. Both lists are real; they are simply not the same list. Until one is chosen, "ten gates" is a slogan rather than a specification, and a strategy cannot be scored against a gate set that changes with the page. This is logged as X-01.
