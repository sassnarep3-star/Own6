Why 3 November matters. The official calendar shows 0 GAMES on 3 November, so a 121-game archive that runs from 20 October to 4 November is complete only if it contains no 3 November fixtures. It contains none, which is why the 2026-11-03 standings snapshot and the 2026-11-05 table differ by exactly the 14 games of 4 November.
