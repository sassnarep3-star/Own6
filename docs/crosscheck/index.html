The line this section will not cross. Re-reading NBA statistics and recomputing coefficients is record-keeping, not evidence of skill. No sportsbook publishes prices through an official NBA page, and NBA Terms of Use §9 restricts gambling use of NBA Statistics, so every market-relative column in this project — price, edge, closing-line value, ROI, reward rank — stays blank and is listed on the Flagged for Review page. A correlation coefficient computed from 121 finals is descriptive; it is not an edge.

Reproduce it

Both the comparison tables and these pages are generated deterministically from the committed CSVs:

python3 scripts/build_crosscheck.py
python3 scripts/check_crosscheck.py

The checker fails if a table row loses its official source link, if an internal link breaks, if a row marked unverified carries a value, or if any comparison row count changes without the data.
