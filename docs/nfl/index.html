RECOMMENDED ORDER

Resolve blockers before a model exists

  1. Get written data-use permission and jurisdiction-specific legal advice.
  2. Choose licensed player/outcome, lineup, injury and timestamped odds feeds.
  3. Define market/settlement rules and freeze a candidate list and holdout protocol.
  4. Run chronological, multiplicity-aware validation; publish failed candidates too.
  5. Only after independent audit, consider a non-monetary leaderboard; material rewards stay disabled until legal signoff.

Every data table row links to an official source for review. An official page is not treated as proof of a value the page does not provide. Missing values remain blank and are flagged.

Research only. No current lines, picks, wagers, measured edge, correlation coefficients, ROI, or strategy rewards are published. Luck cannot be removed; validation can only reduce false discovery and quantify uncertainty. See Flagged for Review, the NFL terms, the AGLC and GameSense.
