The five questions that block everything else

  • Q01 / Q02 - rights and licence. Without written permission and a licensed dataset, no derived value can be published as a performance record.
  • Q03 - verified prices. Without a book and a timestamp, there is no edge to measure, only an assumption.
  • Q08 - prop outcomes. Prop singles, prop combos and same-game parlays cannot be tested at all.
  • Q10 - injury value. Without an archive there is no way to size a starter-out adjustment.
  • Q05 - the model's own skill. Answered, and the answer is negative: the current signal does not beat the close.

How to use this register

A question is closed by evidence, not by opinion. When a source is found, the row changes status, the source link is added, and the change is dated. Suggestions on the Suggestions page are ordered by which questions they would close.

Research only. No wagers, stakes, picks or profitability claims. Blank = unverified; never inferred. Sources are official NFL / club pages unless a row says otherwise. Methods cite NIST, SciPy and scikit-learn for definitions only. Flagged for Review lists every unresolved item.
