What happens to a flagged item

  • It stays blank in every table that would otherwise need it.
  • It is linked from the page it affects, so a reader cannot read a value without knowing its status.
  • It closes only when an official or licensed source removes the doubt, and the row records that source and the date.
Research only. No wagers, stakes, picks or profitability claims. Blank = unverified; never inferred. Sources are official NFL / club pages unless a row says otherwise. Methods cite NIST, SciPy and scikit-learn for definitions only. Flagged for Review lists every unresolved item.
