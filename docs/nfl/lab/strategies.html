Why the combos and parlays cannot be tested yet

Prop combos (S5, S6)

A prop combo needs paired player-level outcomes: the same player, the same game, the outcome on both legs. No prop history or prop price was obtained, so the paired residual file that would feed the copula is empty. See Q08.

Parlays (S7)

A two-leg cross-game parlay needs both legs priced at the same moment, then a joint probability from measured dependence plus the offered payout. Without verified prices the only honest output is the dependence study on Correlation, not a parlay price.

Sizing, without recommending a bet

The library can compute a quarter-Kelly stake from a model probability and an offered price, but publishes no stake because no verified price exists. Sizing an unverified edge is how a research project becomes a gambling problem. See F-N01.
