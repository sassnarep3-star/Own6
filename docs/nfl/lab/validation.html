Reading a "blocked" gate

Blocked is not a technicality. G07 (closing-line value) is blocked for every candidate because no opening/closing price sidecar exists; G05 is blocked because no market probability series exists. A future session that adds a licensed price feed moves these from blocked to pass or fail automatically - the code does not change, only the evidence does.
