Review workflow (choose a path, then implement)

  1. Read the top of the register. SG-01 and SG-06 cost an hour and improve how every other number is read.
  2. Handle the blockers in order. SG-03 (licensed prices) unblocks CLV, de-vigged fair prices and every ROI statement; it is low priority on the formula only because it is expensive.
  3. Pilot anything with confidence <= 2. None of the current fifteen is that speculative, but the rule stays.
  4. Record the decision. Accepted, deferred or rejected - with a date and a reason - in COORDINATION.md.
  5. Implement on a claimed scope. One session, one branch, one file set; no shared file without a request.

What was deliberately not suggested

A live odds widget, a "best bets today" card and a public leaderboard with money prizes were all rejected before scoring. Each requires a licensed price feed this project does not have and each creates pressure to publish before verification. They are recorded here so the decision is not silently reversed later.
