Twelve gates, and the one that is still open

Each gate blocks a specific failure mode and names the artefact that must exist before it can pass. The engine fails closed: an unregistered or missing artefact returns BLOCKED, never PASS. As of this build, 11 of 12 gates are blocked.

A gate that cannot fail is not a gate. The only gate that currently passes is VG-12 (pre-registration), because this register was committed to git before any observation existed. The other eleven need licensed data, and none of them has been talked into passing.

What the gates are protecting you from

  • A 6-bet winning streak that looks like skill. Blocked by VG-07 and the luck test on the strategies page.
  • Ten strategies tested, the best one reported. Blocked by VG-08.
  • An injury signal built after the price moved. Blocked by VG-02 and VG-03.
  • A combo priced as if its legs were independent. Blocked by VG-10 and VG-11.
  • A season-long rate applied to a roster that no longer exists. Blocked by VG-09.
