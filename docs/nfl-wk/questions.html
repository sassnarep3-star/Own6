The five questions that unblock the most

  1. Q-01 (licence). It gates every price, every model output and every strategy. Nothing else can proceed without it.
  2. Q-03 (closing lines). Without a timestamped price there is no edge, no CLV and no leaderboard.
  3. Q-07 (dated depth charts). The injury analysis can count ruled-out starters but cannot date the chart.
  4. Q-11 (paired history). No parlay or prop combo can be priced honestly without it.
  5. Q-12 (effect size). The 200-bet floor is a policy, not a derivation. A pilot would replace it with a number.
