Correlations: signs preregistered, coefficients withheld until they can be measured

Parlay and prop-combo pricing collapses if the legs are treated as independent. The honest way to handle that is to state the expected direction before looking, then measure it on paired data. The register below does the first part. There is no paired data, so all eight coefficients are blank.

Why nothing is filled in. A correlation needs two variables measured on the same unit — the same game, or the same player-game. The verified inputs in this repository are season totals per club, which cannot produce a pair. Any number entered here would be invented, and it would then propagate into every parlay price.

How a coefficient will be computed when the data arrives

  1. Build paired residuals: for each game, the model residual for each leg, so a shared pace shock is not double-counted.
  2. Compute Pearson r on the paired residuals (src/nfl_wk/model.py: pearson).
  3. Report a Fisher-z 95% interval beside it (fisher_ci), and refuse to use the coefficient unless the interval excludes zero.
  4. Cluster by slate where games share a week, because games in the same week are not independent observations.
  5. Feed the joint probability, not the product of marginals, into any combo price.

Method source: SciPy pearsonr documentation.
