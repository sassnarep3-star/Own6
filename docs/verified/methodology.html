Methodology — gates and correlation

This is the compiler's own methodology. It is NOT a sourced fact. No gate has been run on real data, and no correlation value has been computed, because no verified odds or results dataset is available (see Flagged for Review).

Luck control

No method removes variance. The gates above only reduce the chance of mistaking luck for skill. A strategy that passes can still lose money. Results need a long run to separate skill from luck.

Correlation values

Status: Not computed. Pairwise correlations are estimated only from training-period data. Values are left blank until a verified dataset exists.
