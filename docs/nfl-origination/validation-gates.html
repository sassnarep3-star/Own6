How Luck Is Removed From NFL Leaderboard Qualification

In a 272-game NFL regular season, single-game turnover luck (fumble bounces, tipped interceptions, upright kicks) creates a ~6.03% ROI standard error at N = 250 binary bets. Our engine eliminates luck from strategy promotion via four orthogonal statistical barriers:

1. Same-Line De-Vigged CLV (t >= 2.50)

Gate NFL-G07 measures whether originated prices consistently beat the vig-free closing line on the exact same spread/total number — a pre-kickoff skill signal with 3x–4x tighter variance than binary game outcomes.

2. Strictly Proper Scoring Dominance

Gate NFL-G06 requires out-of-sample Brier AND LogLoss to beat the de-vigged closing market on identical games, disqualifying lucky longshot parlay hits that lack calibration.

3. NFL Week-Clustered Block Bootstrap

Gate NFL-G08 resamples entire NFL slate weeks together (n_resamples = 4,000) so correlated Sunday wind troughs or slate-wide injury shocks cannot understate confidence-interval width.

4. Holm-Bonferroni Family-Wise Error Control

Gate NFL-G09 adjusts raw p-values across all M >= 10 registered strategies and feature variants so testing multiple NFL hypotheses cannot sneak a false positive onto the leaderboard.
