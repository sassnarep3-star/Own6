Executive summary

The programme has an origination spine, a results feed, gates, divisions, a luck panel and a decision-readiness table — built by 18 session packs, each of which also wrote its own suggestions and questions. The result was not a lack of analysis but a lack of a decidable form of it: 213 suggestion rows and 210 question rows in 33 registers with 28 different column vocabularies, no cross-references, and no place where the owner could choose a path. This board is that place.

Method, in one paragraph

The builder reads every suggestion and question register under data/, classifies each row onto sixteen decision themes (hand-checked overrides where the wording is ambiguous, keyword fallback otherwise, and the verifier fails if any row lands unsorted), merges the option paths, computes a rank from consensus, row counts and this session's evidence rows against an effort score read from the rows themselves, recomputes coverage metrics from the packs' own files, tests published claims against those metrics, and renders it all with a source link per row. It is deterministic: the same tree builds the same bytes. It implements no suggestion, because the brief asked for review before implementation.

Research and evidence only. Nothing here is a pick, a price or a profitability claim. A blank cell means no confirmed value — not zero. Suggestions on this board are deliberately unimplemented: the owner chooses the path first.
