What this section is

The brief asked for one thing that no existing page did: a place where suggestions can be reviewed and a path chosen before anything is implemented, plus a clear list of the questions, information and answers that must be addressed before a decision is reasonable. The repository already had that material — scattered across 29 suggestion registers and question registers written by 16 different packs, each with its own column names, so nothing could be compared with anything. This board folds them onto one schema, keeps every source row visible with its file and id, and adds the dated official reads that move questions from “open” to “answered” or show precisely what is missing.

Nothing here is implemented. Decision columns are blank on purpose. Pick a path (A/B/C) on the suggestions or paths page and any later session implements only what was chosen.
