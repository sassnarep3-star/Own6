How much of the table is luck

Before any strategy can claim skill, the spread it is trying to explain has to be separated from the spread a coin flip would produce anyway. Using only official numbers: the observed win-percentage variance across the 32 clubs is compared with the binomial variance of a fair coin flip over the same number of games.

Observed win-pct variance0.056970
Coin-flip null variance0.029514
Implied skill variance0.027457
Luck share0.518
Margin SD (points/game)6.179
League points per game23.010

Derivation

  • observed = population variance of win percentage across the 32 clubs in the reconstructed through-Week-9 table.
  • null = mean over clubs of 0.25 / games: the variance of a fair coin flip over that many games, i.e. the spread with no skill difference at all.
  • skill = observed − null. luck share = null / observed.

Roughly 52% of the win-percentage spread across the league at this point in the season is what a coin flip would produce anyway. Any model claiming to explain the standings has to beat that, not merely correlate with it. This is a share, not a probability, and it is one season slice.
