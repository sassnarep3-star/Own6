Lawful Caps — Local / State / Federal

Local law controls here (SF Rent Ordinance)

SF local is more protective than state AB1482, therefore SF’s 1.6% controls. Federal law sets no dollar amount — it tests for discrimination/retaliation. All three layers apply simultaneously; the most protective tenant cap wins.

SF formula

Per SF Admin Code §37.3(a)(1): annual increase = min(60% × CPI published change, 7%). Board publishes each Mar 1 based on U.S. Dept Labor CPI-U Bay Area prior year. Banking allowed additively under same section + SF.gov Learn. License prerequisite §37.15.

State AB1482 interplay

AB1482 ( Civ 1947.12 para (d)(3)) explicitly exempts housing subject to local rent control that restricts increases to less than the state formula — your building. So state 5%+CPI max10% is not your lawful ceiling; SF’s lower figure is. You still owe state notice ( Civ 827) and retaliation protections ( Civ 1942.5 ).
