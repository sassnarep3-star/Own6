Bottom line (tenant-lawyer-proof standard)

A San Francisco tenant lawyer will pass a rent increase when it is (1) ≤ Rent Board figure (now 1.6%) on anniversary + documented bank, (2) licensed (Housing Inventory + fee), (3) ≥12 mo since last increase, (4) 30-day written notice (90-day if >10% in 12 mo) with dollar/percentage/date + bank breakdown, (5) calculated on base rent without rounding up, (6) no retaliation/discrimination, (7) no unapproved passthrough, (8) consistent across units on neutral methodology.
