Governing framework. San Francisco Administrative Code Chapter 37 (Residential Rent Stabilization and Arbitration Ordinance) limits annual rent increases to 60% of the published Bay Area CPI-U increase, in no event more than 7%, for licensed landlords whose units are covered. Building stock: pre–June 13, 1979 ⇒ full coverage. Official code library: SF Admin Code §37.3 ↗.

Where landlords go wrong (2026 practice)

  • Imposing the 1.6% without the Housing Inventory license — the increase is unenforceable until licensed (S-01, S-04).
  • Rounding $63.92 up to $64 — prohibited (S-01).
  • Mailing a 30-day notice and waiting only 30 calendar days — mailed service adds 5 days (S-01, S-04, S-12).
  • Serving Unit 2's 13.1% combined increase on 30 days — defective; 90 days required (S-12).
  • Charging either unit for a new roommate — unlawful (S-01).
  • Noticing an above-AGA amount "subject to Rent Board approval" without filing the petition first — tenants need not pay until approved, and approval is retroactive only to a valid notice date (S-05).
