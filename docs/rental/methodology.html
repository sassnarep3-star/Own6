Verification · how this was built

Methodology & Privacy Protocol

Official-first verification, deterministic computations, the blank-over-unverified rule, and the placeholder protocol that keeps tenant identities out of every published page.

How this was verified

  1. Official-first. Every legal/regulatory value traces to an .gov / .ca.gov / federalregister.gov page (or the official SF code library) read on 2026-11-06 — see Sources. leginfo.legislature.ca.gov, sf.gov and hud.gov pages were fetched and read directly.
  2. Form 571 for history. The complete 45-period AGA table was copied verbatim from the official Rent Board Form 571 PDF (2026-11-06), including its footnote on the two 1992–93 increases.
  3. Computed values are labeled, never passed off as official. Dollar increases and scenario tables are produced deterministically by scripts/build_rental.py from data/rental/scenarios.json using exact decimal arithmetic. They are illustrations, not Rent Board determinations.
  4. Blank beats unverified. Where a value could not be read from an official page (HUD area-level FY2027 FMRs — F-R2; Unit 2's current base rent — F-R7), it is blank and flagged. Nothing is inferred or filled in from secondary sites.
  5. Banking math follows SF.gov exactly: banked percentages are added, multiplied by the current base rent; never compounded or prorated; a skip is bankable only after ≥24 full months without any increase; banked amounts never expire during the tenancy.
  6. Notice periods follow Civil Code §827(b): ≤10% → 30 days; >10% (alone or combined) → 90 days; mail adds 5 days (incorporating CCP §1013).
  7. Privacy protocol. Tenant names replaced by placeholders (Tenants A–F) everywhere, including this page and the repository history of this pack. Dates and dollar amounts preserved exactly as recorded in the underlying documents. No street address beyond 94122 is published. The placeholder mapping is kept only in the private source material, never committed.
  8. No legal advice. This pack informs; it does not represent. SF tenants facing eviction have a right to free counsel (S-11); all tenants can call Rent Board counselors (S-05).
