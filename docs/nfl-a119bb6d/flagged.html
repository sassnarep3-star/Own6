Structural limits that are not bugs

  • The official Game Book contains no snap counts and no player-participation table: a scan of a complete document finds 0 lines containing “snap” and 0 lines containing “participation”. Any depth feature built on playing time therefore needs a source the league does not currently publish in this document.
  • The league publishes no club depth chart: https://www.nfl.com/teams/houston-texans/roster/depth-chart/ returns the league's own 404 page. The club's own chart is a club document and is labelled unofficial by the club.
  • The Game Book carries the league's copyright statement, quoted on the Game Books page. This pack records the URL and the hash and publishes the facts; it does not redistribute the documents. A written position from NFL Enterprises would close the licence question.
  • Depth of a replacement is published as a lower bound, counted only from players the Game Book shows were unavailable. It is not a depth-chart rank and must not be used as one.
