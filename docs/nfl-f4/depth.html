The case that matters: a questionable starter in front of an unavailable backup

New England running back Rhamondre Stevenson is Questionable. Behind him the club lists TreVeyon Henderson 2nd — and the official report has Henderson Out. So the contingency plan is not the second string; it is Corey Kiner, third string, with Lan Larison fourth. That is a different price than "Stevenson questionable". The contingency columns exist to make that two-step visible instead of collapsing it into a single injury headline.

Two refusals

  • A missing designation is not health. If the official report does not name a player, the row says not_designated, not "healthy". The report lists participation, not fitness.
  • Only clubs whose chart was read are populated. A roster sorted by jersey number is not a depth chart, so the other 30 clubs are absent rather than guessed at.
