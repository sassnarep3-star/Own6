What would change a FAIL to a PASS

G1 and G2 need history: the price store has to accumulate settled closes across weeks, which the capture protocol already supports retroactively. G3 and G4 need the same. G5 needs official player-level stat lines, which would come from an official stats source, not from a scraped box score. None of these requires a model change; all of them require time or a decision.
