Reading the three measured values

  • C1 margin vs total, r = −0.161 (n = 137, p = 0.061). Not distinguishable from zero at the 5% level, and the interval spans zero. The honest read: no demonstrated dependence, so a same-game side+total parlay should be priced at independence for now, with the caveat that a real effect this size would need roughly 400+ games to resolve.
  • C2 points-for vs points-against, r = 0.075 (n = 274). Essentially zero, as expected: a team's offence and defence are separate processes. This is a useful negative result — it means offence and defence must be modelled and priced separately, which is what the depth page already assumes.
  • C3 absolute margin vs total, r = −0.016 (n = 137). No blowout/total link. Totals in mismatched games carry no extra information from this pair.

What is not computed, and why that is the answer

  • C4 rest differential. The most-cited public NFL signal has no verified rest column in this pack. Game dates could be differenced, but Thursday and Monday games already encode rest, so deriving it would smuggle an assumption into a "measured" number.
  • C5 depth deficiency vs margin. One week of depth snapshots for two clubs. A correlation needs the deficiency score and the margin for the same games across ≥100 observations.
  • C6 closing spread vs margin. One settled game. The store is built to accumulate exactly this, and the row will fill itself as closes settle.
