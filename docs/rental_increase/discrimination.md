# Discrimination Analysis: Raising Rent on One Unit vs Both Units

## Legal Analysis
- **Discrimination Risk**: Raising rent on only one unit (e.g., Unit 1 but not Unit 2) could trigger discrimination inquiries if tenants are in protected classes (race, gender, disability, etc.) [Fair Housing Act / SF Ordinance]
- **Normal Business Practice**: Applying the same 1.6% cap to all covered units in the same building/location is standard and avoids discrimination claims [SF Rent Board]
- **Recommendation**: Raise rent on **both units** simultaneously (if applicable) using the same 1.6% calculation to ensure consistency and avoid discrimination inquiries [SF Rent Board / Legal Counsel]
- **Exception**: If one unit is not due for an increase (e.g., last increase was within 12 months), do not increase; bank the allowance instead [SF.gov Learn](https://www.sf.gov/learn-about-rent-increases-san-francisco?_gl=1*1aixd12*_ga*MTEwODA2MzMyMS4xNzA2ODkwMTk0*_ga_BT9NDE0NFC*MTcwNjg5MDE5NC4xLjAuMTcwNjg5MDE5Ni4wLjAuMA..)
