Category · Signal test

Is there skill, or is it luck?

The candidate signal is deliberately simple: a ridge team-rating model fitted on point margin and total, with one league-wide home advantage, refitted before every game so no future result can leak backwards. It is scored on 61 games it had never seen, with a proper scoring rule, a bootstrap interval and a paired test against the naive benchmark.

Verdict

Point estimate: the model beats picking the home team on accuracy (67.2% vs 50.8%) and on Brier score (+0.130 skill). But the paired McNemar test (p = 0.0639) and the bootstrap interval on Brier skill (-0.038 to +0.296) both fail to exclude luck. With 61 games this is the expected outcome: the honest statement is preliminary signal, unproven.

What would change the verdict: a fixed pre-registered rule, several hundred out-of-sample games, a market comparison after vig, and a multiple-testing correction across every candidate tried. None of those exist today, which is exactly what the validation gates record.
