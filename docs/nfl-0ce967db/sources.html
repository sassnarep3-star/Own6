The publication rule

A value is published only if it is (a) text read from the official page named in its source link and logged above with a clock, or (b) arithmetic on such values with the derivation shown in the row. Everything else is an empty cell with a flag. Market prices are not published by any official page, so every price, ROI, CLV and units cell on this site is empty by written policy, not by omission.

Two limitations, stated plainly

1. No raw page bytes were retained. This sandbox has no network route to nfl.com from a shell — only GitHub, npm and PyPI are reachable — so official pages were read through a page-fetch tool that returns text. The sha256 values in the log cover the transcription artifacts written from that text. They prove the artifacts were not edited afterwards; they cannot independently prove the page said it. A reader who wants that guarantee must open the linked page themselves.
2. Reading is manual, not scheduled. The NFL terms restrict systematic retrieval of the Services without express written consent. This project therefore performs single manual reads and does not run a crawler. Any weekly capture, archive or price feed is blocked until consent exists — see the Q/I/A page, question Q20.

Reproducing every number

  • python3 src/nfl_0ce967db/run.py — rebuilds the results feed, the model ledger, the scores, the luck panel, the demotion state and the week-11 batch from committed inputs. No network. Deterministic.
  • python3 src/nfl_0ce967db/correlate.py — rebuilds the six correlations with their intervals.
  • python3 scripts/build_nfl_0ce967db.py — rebuilds these pages.
  • python3 scripts/check_nfl_0ce967db.py — the verifier: source links, blank policy, no input controls, registered family size, reconciliation, determinism.

The pre-registration that fixes the model family, thresholds and evaluation protocol was committed before any model code existed; its hash is cited in every model row.
