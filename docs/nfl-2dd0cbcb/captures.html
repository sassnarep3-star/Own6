How to read these tables

  • A blank game status is what the page printed. It is not "available", not "questionable", and not a data error in this pack — it is an open item in the register inherited from the morning session.
  • Every cell here is a transcription of page text. Values the page did not print (position on the reserve list, for instance — that column is blank for all 25 rows) are published blank, never filled in from another source.
  • These reads are dated. A reader on 2026-11-26 sees a page that has moved on: the Week-12 reports will exist by then, and this pack's value is the dated series, not a current view.
