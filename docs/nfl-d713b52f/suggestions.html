The three that matter most, in one paragraph each

S06 — get a written price-policy decision before any more pricing work

Nine requirement rows are blocked on one missing input and no amount of engineering can clear them. Either the owner supplies a licensed price archive or the project formally drops ROI, CLV and every residual column. Both are defensible; continuing to build plumbing around an input that will never arrive is not.

S03 — adopt a three-level definition of "verified"

The site currently uses one word for a certified count, a number the league itself labels Unofficial, and a number the pack derived. That is the single easiest way for a careful site to mislead a reader. A legend on every table fixes it in an afternoon.

S05 — read the 2024 and 2025 finals next

One season cannot produce a holdout, and a holdout is what turns a backtest into a decision. The pages are published, the read is cheap, and it unblocks calibration, designation scoring and the ablation at the same time.
