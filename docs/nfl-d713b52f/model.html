The 16 games the model refuses to score, and why

A margin model cannot forecast a club's first game without borrowing a number from a game played inside the same week. That is same-week information, so those games are refused rather than scored. Publishing the refusal is the difference between a 150-game claim and an honest one: 150 corpus = 134 scored + 16 refused for same-week information.

The removal-of-luck panel

The score is split the only way that means anything: the part the model could remove by being better calibrated (reliability), the part it earns by saying different things on different games (resolution), and the part nobody can remove because football is football (uncertainty). The split is computed on five fixed probability bands, not on the exact forecast values — an exact-value split puts one game in each band, makes reliability equal the Brier score and would look tidy while measuring nothing.

The panel says the model is not over-fit to luck: reliability is only 5.9% of the score, so almost none of it can be recovered by recalibration alone. What it does say is worse for the model — the bands are badly ordered in the middle. Where the model says a game is close to a coin flip (0.40–0.50), home clubs actually won 32.0% of the time; where it says 0.50–0.60, they won 44.0%. The model is confident in the wrong direction in the games it should be least sure about.

reliability is the part of the score the model could remove by being better calibrated; resolution is the part it earns by saying different things on different games. Bins are fixed probability ranges, not exact values: an exact-value split puts one game in each bin and makes reliability equal the Brier score, which measures nothing. If bins_used equals n, the panel is degenerate and must not be quoted. The bootstrap resamples whole weeks.

What is deliberately absent

Parlay and prop-combo scores (no validated joint probability exists), ROI and CLV (no price), promotion (no prospective sample), and any injury or personnel term in the model (the ablation is registered but coverage is 4 games). Each absence has a gate on the readiness page.

Every value on this page was read from the official NFL page linked beside it on 2026-11-19 UTC, or is arithmetic on such values with the derivation shown. No market price exists on any official page, so price, ROI and CLV columns are blank by policy. No profitability claim is made anywhere. Blank is not zero and blank is not healthy.
