What this proves and what it does not. The league's own report establishes player availability. A depth deficiency - how much a unit loses when a second or third string player starts - needs the club's depth order and the replacement's expected snap share. The first exists for 8 clubs in this repository and the second exists nowhere as an official source, so every deficiency index stays blank. Suggestion S-10 closes the first half of that gap.
