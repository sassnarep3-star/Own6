What this pack adds

  • Removal-of-luck panel — every record and hit rate is published beside the exact binomial distribution luck alone would produce.
  • Control baselines — a pre-registered seeded coin and a rating-favourite run on every window.
  • Availability graph — expected-vs-actual nodes with evidence levels; nothing is inferred.
  • Injury deltas — timestamped reads; the delta is the signal, never the level.
  • Model-output ledger — probability plus full input vector per game.
  • Drift alarms — per-source contracts; the build fails loudly on drift.
  • Proper-score divisions — singles eligible; combos behind the joint-evidence gate.
