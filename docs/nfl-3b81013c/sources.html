Verification limits, stated plainly

  • Read once. Each official page was read on 2026-11-12. Injury status changes during the week and the inactive list supersedes the practice report 90 minutes before kickoff.
  • Transcription risk. Values were transcribed by an automated agent, not by a human double-entry process; the URL on every row exists so a reviewer can check any single value.
  • No market data. No sportsbook price was read, licensed, quoted or compared. Terms of use sections 1.3, 11(f) and 12 restrict reuse, automated harvesting and gambling use.
  • Priors are assumptions. Home-field advantage and margin spread are declared modelling priors, not official league statistics; no official NFL page publishes either.
  • Structural weights are uncalibrated. The positional weights and string tiers are an ordinal prior built with no historical fit; the pages say so wherever they are used.
  • Copula columns are approximate. The joint probabilities use a second-order Mehler expansion, which is close at moderate correlation and diverges near the bounds.
