How luck is controlled rather than assumed away

  1. Multiplicity. Ten strategies tested at once inflate the chance of a false winner, so the family of p-values is Holm-adjusted before any rank is awarded.
  2. Clustering. Bets inside one NFL week are not independent, so the interval is a slate-clustered bootstrap rather than an independent-sample interval.
  3. Out-of-sample only. Parameters are frozen before the test week, and the package rejects any non-training row in a correlation estimate.
  4. Proper scoring. Accuracy is not enough; the holdout Brier or log-loss must beat the de-vigged market, which is the only comparison that removes the price from the result.
  5. Selection disclosure. The number of strategies tried is published, because a winner chosen from an undisclosed search is not evidence of skill.
