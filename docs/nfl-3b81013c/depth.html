Injuries and depth

Injuries, starters and the backup who replaces them

Every starter-level entry on the official Week 10 injury report, with the replacement named only where an official source names them, and a severity index that stays blank when the incoming depth string is unknown.

The severity column is deliberately sparse. A weight can only be assigned when an official source states which string the replacement player came from. For most entries that is not stated, so the cell is blank. Three verified quarterback cascades are the only fully weighted entries.

Starter-level entries on the official Week 10 injury report

Practice status is transcribed from the official report: FP is full participation, LP is limited, DNP is did not participate. Game status such as Out or Injured Reserve is recorded separately. The structural severity index is a positional weight multiplied by the verified incoming string tier (1.00 for a first-string starter down to 0.45 for a second-string replacement), or by 0.15 for a limited participant. It is an uncalibrated ordinal screen, not points.
