How verification works here

Each register row carries exactly one of three labels. verified means the value is stated on an official NFL page read during this session and the exact URL is in the row. computed means the value is arithmetic or model output over verified inputs, reproducible by rerunning the builder and the checker. unverified means the value is blank, is rendered as a hatched empty cell, and appears on the Flagged for Review page. No row is ever promoted from unverified by inference.

The checker scripts/check_nfl_3b81013c.py rebuilds all eleven pages and fails if any byte differs, recomputes the league average, every per-game rate, every originated spread and total, and every pricing example, and rejects any unverified row that carries a value.

Generated from data/nfl_3b81013c/*.csv by scripts/build_nfl_3b81013c.py and verified by scripts/check_nfl_3b81013c.py. Every table row links to the official NFL page it came from and to a recognised methodology reference. A blank hatched cell means the value is not confirmed from an official source and was deliberately left empty. This pack publishes no market price and makes no wagering recommendation: NFL.com Terms of Use sections 1.3, 11(f) and 12 restrict reuse, automated harvesting and gambling use.
