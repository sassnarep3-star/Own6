What the official sources do and do not establish

The NBA pages establish definitions, availability limits and contractual restrictions. They do not establish any predictive relationship, any price, any correlation value or any return. The statistical references define the mathematics of the tests — they do not endorse a betting strategy, and none of them is evidence that any strategy here works.

The repository CSVs carry a per-row official source_url to the NBA game page for each result. That link identifies where the score came from; it is not a certification of every derived value, and this build does not re-fetch game pages. Re-verification of those rows belongs to the existing verification ledger, not here.

Absences, stated as absences

  • No verified sportsbook price archive. The only prices in the repository are ESPN-carried quotes for one slate. They are a secondary relay, not a first-party record.
  • No closing-line history. Closing-line value cannot be computed, so SG07 is weaker than it would be with it.
  • No licensed player game logs. Prop and combo families cannot be tested.
  • No NBA authorisation for gambling-related use. Publishing derived numbers from NBA data is exactly what §9 restricts.
