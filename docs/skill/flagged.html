Items this build resolved rather than flagged

  • SG06 direction. The paired loss comparison was initially written with the subtraction inverted, which would have credited a model that lost more than the market. Corrected before publication and covered by a test.
  • SG08 semantics. Calibration was initially required to beat climatology, which conflates calibration with discrimination and would fail a well-calibrated constant forecast for the wrong reason. Discrimination is scored at SG06; SG08 now tests calibration only.
  • Published correlations that did reproduce. The home/away and same-date point estimates recompute to within 2×10⁻⁵ and are not flagged.

How to request a change

Open an issue on the repository referencing the flag ID. A change to a flagged value must arrive with its own official source, or it stays blank. Flags do not delay publication; they are the mechanism by which an unpublished claim stays visible instead of disappearing.
