The interval is the finding

Home vs away score, r = 0.2004. Nominal p = 0.055, just above 0.05, and the Fisher interval runs from -0.0046 to 0.3892. The interval nearly touches zero. Calling this "a correlation of 0.20" without that interval would overstate what 92 games can show.

Same-date margins, r = 0.1052. The nominal p-value of 0.047 looks significant. It is not. Every game appears in many of the 357 pairs, so the pairs are not independent observations. Resampling whole dates instead of pairs gives an interval of -0.0749 to 0.2205, which contains zero. The naive p-value is an artefact of pseudo-replication — the same mistake that inflates most amateur parlay-dependence claims.

Rest differential does not reproduce. The published value is -0.0162; the recomputation from the same file and the same n gives -0.0801. The difference of more than 0.06 is far outside rounding. Either the published value used a different rest definition that is not documented, or it is wrong. It is flagged rather than silently corrected, because the definition of record belongs to the file's owner.

How to measure a correlation you could actually use

  1. Pair the residual, not the raw value. Correlating two raw totals mostly measures shared pace.
  2. Report n, the interval, and the clustering unit (game, date, player, season).
  3. Resample the clustering unit, not the observation, when the unit repeats.
  4. Pre-register the pair before looking. Choosing the pair after seeing the scatter is a multiple-testing problem in disguise.
  5. Never multiply marginals into a parlay price without stating the dependence model.
