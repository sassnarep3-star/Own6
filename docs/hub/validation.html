Validation gates

What a strategy must pass before it can rank, and how luck is removed.

A strategy is skill-eligible only if G1 (calibration CI strictly > 0 against a baseline) and G2 (discrimination at n ≥ 100) pass. Everything else is tracking. Process gates (G3, G4) do not make a strategy eligible. Current eligible strategies: 0.
