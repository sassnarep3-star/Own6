Validation gates and the demotion gate (live → paper)

Demotion gate definition. A live strategy returns to paper the moment any DG rule fires. DG-01/DG-02 use luck-resistant statistics (closing-line value and holdout ROI lower bounds) rather than raw ROI. DG-04 (stale inputs) and DG-05 (feed integrity) are evaluable today; the rest arm when a price archive exists. State machine: paper → live only when every VG gate is satisfied; live → paper immediately on any DG trigger; re-promotion requires a fresh full-gate pass.

Close-capture protocol (fills the store's close rows)

  • At the market's kickoff window, re-read the official injury report and standings.
  • Recompute the model with the same published formula and parameters; that number is the close.
  • Record it in the close row with the capture date and input links; never backfill a close from the result.
