Luck-removal protocol

  • Walk-forward grading (prior games only) — no look-ahead; code: scripts/model.py
  • Shrinkage k=8 (strength) / k=4 (scoring) toward league average — early-season noise damped
  • Pre-registration: gates & strategy rules written before results (this page + strategies.md)
  • Baseline comparisons (coin / expanding home-win / expanding mean) — raw accuracy never trusted
  • 10,000-resample paired bootstrap (seed 42) on log-loss difference; CI crossing zero = fail
  • Multiple-testing log for DSR-style deflation (currently N=1)
