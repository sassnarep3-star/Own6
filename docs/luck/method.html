Method and numerical checks

The exact formulas, the cross-check against SciPy and statsmodels, and the read status of every cited method reference.

Every figure on this page is arithmetic from the formulas in src/own6/power.py: a statement of how much evidence would be needed. No NBA result, sportsbook price, correlation estimate or return is observed, scraped or inferred here. Values that cannot be confirmed stay blank and are marked unverified; a blank is not zero.

Formulas

All figures are closed form; no simulation and no fitted parameter is involved.

per-bet mean mu = p * d - 1 ; variance = p(d-1)^2 + (1-p) - mu^2 (d = decimal odds, p = win probability) required n n = ceil( ((z_{1-alpha} + z_{power}) * sigma / mu)^2 ) one-sided test detectable ROI mu_min = (z_{1-alpha} + z_{power}) * sigma / sqrt(n) Bonferroni alpha' = alpha / m ; expected false positives = m * alpha Benjamini-Hochberg q_(i) = min over j >= i of (m/j) * p_(j) Fisher z n = ceil( ((z_{1-alpha/2} + z_{power}) / atanh(r))^2 + 3 ) Wilson interval standard score interval for a binomial proportion p-value exact binomial upper tail, evaluated in log space (no normal approximation)

Assumptions and limits

The requirements assume independent, fixed-price, equal-stake bets and a known true edge. Real markets move, stakes vary, and same-game legs are dependent, so the parlay rows are an independence baseline. The normal approximation is used for sample-size planning, while the p-value for an observed record is exact binomial. Nothing on this site observes a price or a result: the values are requirements, and the published leaderboard remains empty.
