The optional strict command fails while coverage gaps exist. CI builds a current-tree artifact and checks repeatability and parser regressions; it does not enforce committed-snapshot freshness. A green CI check is not a green factual-verification gate. External HTTP reachability and fragment existence are not checked by this offline tool.
