How a number gets here

  1. An official page is read and the value is transcribed into a register with its URL and read date (data/nfl_desk/*.csv).
  2. src/nfl_desk derives every published figure from those registers - arithmetic, fits, bootstraps, gate states.
  3. The builder writes the derived registers and renders the pages; --check requires byte equality, so a page can never disagree with its own code.
  4. The checker enforces row-level sourcing, blank-not-guessed cells, table alignment and link integrity; CI runs both on every push to main.

Every table row links to the official page actually read for it. A blank cell means no confirmed value exists, not zero. Values labelled model assumption are the model's own dials and are never presented as facts.
