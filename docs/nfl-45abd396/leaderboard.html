What is deliberately absent. There is no ROI column, no staking column and no closing-line column. NFL.com publishes no price, so a return cannot be computed without inventing one. The brief's rule that a lucky staking run must not mask a bad signal is met by having no staking column at all rather than by a column filled with a guess.
