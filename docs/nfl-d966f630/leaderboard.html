Leaderboard

Signal and staking, ranked separately and never averaged.

Requirement 5, in the structure rather than the prose: two tables, two ranks, and no column shared between them. The checker enforces it - the signal table may not contain a stake, unit or payout column, and the staking table may not contain an accuracy or error column.

Signal block - how good the numbers are

Ranking is on the Brier skill score - the model's probability error against the same event's own base rate - not on raw Brier. That matters because a favourite-win event and a cover event have different base rates: raw Brier of 0.19 on a 73%-hit-rate event is not better than 0.25 on a coin flip, and a board that compared them that way would rank structure rather than skill.
